# Teste de Reflexo

Jogo simples de teste de reflexo, feito em HTML, CSS e JavaScript puro (sem dependencias ou build step).

## Como jogar

1. Abra o arquivo `index.html` no navegador.
2. Clique no quadro cinza para comecar.
3. Espere o quadro ficar verde e clique o mais rapido possivel.
4. Se clicar antes da hora, a rodada e invalidada e voce tenta de novo.

## Funcionalidades

- Cronometragem do tempo de reacao em milissegundos.
- Recorde pessoal, ultima tentativa e media das ultimas 5 tentativas.
- Historico das ultimas jogadas.
- Pontuacoes salvas no localStorage do navegador.
- Botao para zerar o recorde.

## Tecnologias

Apenas HTML, CSS e JavaScript, sem frameworks. Basta abrir o arquivo `teste-de-reflexo/index.html` diretamente no navegador.
